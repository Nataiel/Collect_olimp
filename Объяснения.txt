📊 ГЛОБАЛЬНЫЕ ПЕРЕМЕННЫЕ

# Поток для запуска сервера в фоне
server_thread = None

# Флаг работы сервера
server_running = False

# Файл для хранения данных о выборах олимпиад
data_file = 'olympiad_data.json'

# Путь к выбранному Excel файлу
excel_file = None

# Словарь с данными учеников: {класс: [список ФИО]}
school_data = {}

# Список предметов олимпиад
subjects = ['математика', 'русский язык']

# Словарь с данными участия: {класс: {ученик: {предмет: bool}}}
olympiad_data = {}

# Флаг первого запуска программы
first_run = True

# Объект Flask приложения
flask_app = None


🔧 ФУНКЦИИ НАСТРОЙКИ FLASK
setup_flask_app()
	Назначение: Создает и настраивает веб-сервер Flask
	Использует глобальные: flask_app, school_data, subjects, olympiad_data
	Работает с функциями: save_olympiad_data(), get_statistics()
	Что делает:
		Создает объект Flask приложения
		Определяет HTML шаблоны для страниц
		Настраивает маршруты (URL адреса)
		Связывает URL с функциями-обработчиками

Вложенные функции Flask:
home()
	Назначение: Главная страница с выбором классов
	Использует глобальные: school_data
	Что делает: Показывает сетку классов из загруженного Excel файла

class_page(class_name)
	Назначение: Страница конкретного класса с таблицей выбора
	Использует глобальные: school_data, subjects, olympiad_data
	Что делает: Отображает таблицу с учениками и чекбоксами для выбора олимпиад

save_data(class_name)
	Назначение: Сохранение выбранных олимпиад для класса
	Использует глобальные: school_data, subjects, olympiad_data
	Работает с функциями: save_olympiad_data()	
	Что делает:
		Обрабатывает данные из формы
		Обновляет olympiad_data
		Сохраняет в файл
		Показывает сообщение об успехе

reset_class(class_name)
	Назначение: Сброс всех выборов для конкретного класса
	Использует глобальные: olympiad_data, subjects
	Работает с функциями: save_olympiad_data()
	Что делает: Устанавливает все чекбоксы в False для указанного класса

stats_page()
	Назначение: Страница со статистикой участия
	Использует глобальные: school_data, subjects, olympiad_data
	Что делает: Показывает статистику по всем классам в виде таблиц

api_stats()
	Назначение: API endpoint для получения статистики в JSON формате
	Использует глобальные: school_data, subjects, olympiad_data
	Что делает: Возвращает статистику в machine-readable формате

📁 ФУНКЦИИ РАБОТЫ С ДАННЫМИ
load_students_from_excel(file_path)
	Назначение: Загрузка данных учеников из Excel файла
	Использует глобальные: school_data
	Изменяет глобальные: school_data
	Что делает:
		Читает все листы Excel файла
		Имя листа = название класса
		Из первого столбца извлекает ФИО учеников
		Заполняет словарь school_data

reset_olympiad_data()
	Назначение: Полный сброс всех данных о выборах
	Использует глобальные: school_data, subjects, olympiad_data
	Изменяет глобальные: olympiad_data
	Работает с функциями: save_olympiad_data()
	Что делает: Устанавливает все чекбоксы для всех учеников во всех классах в False

load_olympiad_data()
	Назначение: Загрузка ранее сохраненных данных из файла
	Использует глобальные: data_file, school_data, subjects, olympiad_data
	Изменяет глобальные: olympiad_data
	Работает с функциями: save_olympiad_data()
	Что делает:
		Загружает данные из JSON файла
		Проверяет целостность данных
		Добавляет недостающих учеников/классы
		Сохраняет обновленные данные

save_olympiad_data()
	Назначение: Сохранение текущих данных в файл
	Использует глобальные: data_file, olympiad_data
	Что делает: Записывает словарь olympiad_data в JSON файл

get_statistics()
	Назначение: Подсчет статистики для отображения в GUI
	Использует глобальные: school_data, subjects, olympiad_data
	Что делает: Считает количество выбранных олимпиад по каждому предмету для каждого класса

🖥️ ФУНКЦИИ УПРАВЛЕНИЯ СЕРВЕРОМ
run_server()
	Назначение: Запуск веб-сервера Flask
	Использует глобальные: server_running, first_run, data_file, flask_app
	Изменяет глобальные: server_running, first_run
	Что делает: Запускает Flask приложение на порту 5000

stop_server()
	Назначение: Остановка веб-сервера
	Использует глобальные: server_running
	Изменяет глобальные: server_running
	Что делает: Устанавливает флаг остановки сервера

🎮 GUI ФУНКЦИИ
load_excel_file_gui(file_label, stats_tree)
	Назначение: Обработчик кнопки загрузки Excel файла
	Использует глобальные: excel_file, data_file
	Работает с функциями: load_students_from_excel(), load_olympiad_data(), reset_olympiad_data(), update_statistics_gui()
	Что делает:
		Открывает диалог выбора файла
		Загружает данные учеников
		Спрашивает о загрузке предыдущих выборов
		Обновляет интерфейс

reset_all_data_gui(stats_tree)
	Назначение: Обработчик кнопки сброса всех данных
	Работает с функциями: reset_olympiad_data(), update_statistics_gui()
	Что делает: Сбрасывает все выборы и обновляет статистику

start_server_gui(status_label)
	Назначение: Обработчик кнопки запуска сервера
	Использует глобальные: server_thread, server_running, school_data
	Работает с функциями: run_server()
	Что делает: Запускает сервер в отдельном потоке и обновляет статус

stop_server_gui(status_label)
	Назначение: Обработчик кнопки остановки сервера
	Работает с функциями: stop_server()
	Что делает: Останавливает сервер и обновляет статус

open_browser_gui()
	Назначение: Обработчик кнопки открытия браузера
	Использует глобальные: server_running
	Что делает: Открывает веб-интерфейс в браузере по localhost:5000

update_statistics_gui(stats_tree)
	Назначение: Обновление таблицы статистики в GUI
	Работает с функциями: get_statistics()
	Что делает: Заполняет таблицу актуальной статистикой

setup_gui()
	Назначение: Создание всего графического интерфейса
	Что делает: Создает все элементы GUI и связывает их с функциями-обработчиками

🔄 СХЕМА ВЗАИМОДЕЙСТВИЯ ФУНКЦИЙ
Главный поток:
main() → setup_flask_app() → setup_gui() → GUI цикл
                    ↓
              Функции Flask (веб-интерфейс)
                    ↓
           save_data() → save_olympiad_data()
           reset_class() → save_olympiad_data()
                    ↓
Поток сервера: run_server() → Flask app (отдельный поток)
                    ↓
GUI функции → управление сервером и данными

Ключевые цепочки вызовов:
	Загрузка данных:
		load_excel_file_gui() → load_students_from_excel() → load_olympiad_data() → update_statistics_gui()
	Работа с веб-интерфейсом:
		save_data() → save_olympiad_data()
		reset_class() → save_olympiad_data()
	Управление сервером:
		start_server_gui() → run_server()
		stop_server_gui() → stop_server()

	Обновление статистики:
		update_statistics_gui() → get_statistics()
