Данная программа разработана для использования исключительно в операционной системе Windows.
Для корректной работы с шаблонами .docx и формирования документов требуется установленный Microsoft Word 
(или другой офисный пакет с поддержкой формата DOCX и возможностью программной работы с ним через python-docx).
Программа находится на стадии бетта-тестирования. Некоторые функции могут работать нестабильно.
Разработчик не несёт ответственности за возможные потери данных или некорректное формирование документов.
Рекомендуется создавать резервные копии исходных файлов перед использованием.

📌 Основные возможности

    Загрузка данных учеников из Excel

    Поддерживаются файлы .xlsx / .xls, выгруженные из ГИС СО «ЕЦП» (Электронный журнал).
    Автоматически распознаются листы с классами (например, 4А, 5Б, 8В и т.д.).
    Поддерживаются классы с 4 по 11.

    Веб-интерфейс для сбора данных

    После запуска встроенного сервера открывается локальный сайт.
    Учитель или администратор отмечает для каждого ученика, в каких олимпиадах он участвует.
    Удобное массовое проставление галочек — клик по названию предмета отмечает/снимает всех учеников в классе.
    Данные автоматически сохраняются в olympiad_data.json и доступны при повторном открытии программы.

    Формирование заявлений

    На основе шаблона .docx создаются персонализированные заявления для каждого класса.
    Поддерживаются автоматические замены:
        %ФИО% — ФИО ученика
        %Класс% — класс
        %олимпиады% — список выбранных предметов
    Готовые файлы сохраняются в папке Заявления.

    Формирование грамот для победителей и призёров

    Загружается протокол результатов ВсОШ ШЭ (выгрузка из РБДО).
    Программа автоматически обрабатывает данные и создаёт грамоты по классам.
    Поддерживаются замены в шаблоне грамоты:
        %ОО% — образовательная организация
        %Класс% — класс ученика
        %Предметы% — предметы с результатами
        %Фамилия%, %Имя% — части ФИО
        %призёр и победитель% — статус участника
        %окон% — окончание слова «предмет» (у/ам)
    Готовые файлы сохраняются в папке Грамоты.

    Экспорт в Excel
    Формируется отчёт Отчёт о выборе предметов ВсОШ ШЭ.xlsx с:

    отдельными листами по каждому предмету со списком учеников
    статистикой по классам
    процентом участия в классе и по школе

    Локальный сервер

    Встроенный сервер на Flask.
    Доступен по локальной сети (http://:5000).
    Создаётся ярлык Выбор предметов ВсОШ.url для быстрого доступа.
